# AuSoCom — Aula Sound Commander

AuSoCom (Aula Sound Commander) is a desktop application for organizing audio files and input/output devices into reusable audio scenes, then arranging scenes into a show. A scene defines which sources are routed to which outputs, along with per-source volume, delay, mute, and routing levels.

## Tabs

- **Files** — Add audio files, edit their short names and playback start/end times.
- **Input Devices** — View and rename discovered input devices. Mark devices as favorites or have them automatically included in new scenes.
- **Output Devices** — View and rename discovered output devices, with the same favorite and auto-add options.
- **Scenes** — Create or duplicate scenes and manage each scene’s file/device inputs, outputs, fade-in/fade-out times, and auto-start setting. Adjust input/output volume and mute controls, and edit routing levels in the matrix.
- **Show** — Build an ordered show from existing scenes, reorder or navigate between them, and start scenes. The selected scene’s controls are available alongside the show list.

Live scene audio and device routing are currently supported on Windows only.
